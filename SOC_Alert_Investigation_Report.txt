Sysmon Event ID 1 recorded the execution of `sdbinst.exe` under the SYSTEM account. Its parent process was `svchost.exe`, hosting the Windows Program Compatibility Assistant service (`PcaSvc`).

The executable was located in the Windows System32 directory. Authenticode verification returned `Valid`, with Microsoft Windows as the signer.

**Conclusion**
The observed process execution is consistent with legitimate Windows compatibility-management activity. The available evidence does not establish malicious activity.

**Disposition:** Likely benign; retain the alert and investigation evidence for audit purposes.

**Evidence collected:** Sysmon process-creation event, command line, parent process, execution account, SHA-256 hash, and digital-signature verification.

Two alerts generated by Wazuh Rule 92058 were investigated (November 23 and November 24, 2026).

- Executable: `C:\Windows\System32\sdbinst.exe`
- Command line: `sdbinst.exe -m -bg`
- Parent service: Windows Program Compatibility Assistant (`PcaSvc`)
- Execution account: `NT AUTHORITY\SYSTEM`
- SHA-256: `12CD20D87A62F4A8B2D26149A58664EF32581565813CE90D2BE103C27A784930`

The executable's Authenticode signature was verified as valid and issued by Microsoft Windows.

**Final disposition: Likely benign / expected Windows activity.**

The rule correctly identified behavior associated with MITRE ATT&CK T1546.011 (Application Shimming). However, the observed evidence does not demonstrate malicious shimming or persistence.

The alerts should remain documented as investigated detections, not be deleted or automatically suppressed.
